## Chapter 03 — Stack & Heap Deep Dive

> "The Stack optimizes execution. The Heap optimizes flexibility. Modern software needs both."

---

# 📖 Chapter Overview

This chapter builds upon the Memory Fundamentals chapter and explores how modern computers manage memory while a program is running.

Instead of only learning the definitions of Stack and Heap, this chapter explains:

- Why they were invented
- How they work internally
- How functions use the Call Stack
- What a Stack Frame actually contains
- Why Stack is faster
- Why Heap is flexible
- Where these concepts are used in real software systems

By the end of this chapter, you should understand how programs execute functions and manage memory like a software engineer.

# 💡 Key Takeaways

- Every thread has its own Stack.
- Every function call creates a Stack Frame.
- Stack follows LIFO.
- Heap provides dynamic memory.
- Stack is optimized for speed.
- Heap is optimized for flexibility.
- Modern software requires both.
